Why Programming Still Matters in the Age of AI
During my undergraduate study, I learned how to use Arduino and the basic logic behind its code. At that time, I did not think much about AI writing code for me. But now, after using AI in my own projects, I understand more clearly why learning programming is still important.
In one of my Arduino projects for my portfolio, I used AI to help me write part of the code. I mainly used it when I was stuck or when I needed a quick draft. The code AI gave me could run, and at first it looked fine. But when I tested it in my interactive installation, I found that it did not work exactly how I wanted. The sensor response was sometimes too slow, and some trigger conditions were not stable. So even though the code was not “wrong,” it was still not right for my project.
Because I had learned the basic Arduino logic before, I could read the code and understand what each part was doing. This helped me change the code much faster. I could adjust the timing, the input condition, and the output behaviour by myself. If I had not known the basic principles, I think I would have just kept asking AI to rewrite the code without really knowing what to fix.
This experience made me think that learning programming is still useful in the AI age, but maybe for a different reason. It is not only about writing every line by hand. It is more about understanding how the system works, so we can check whether AI’s output really matches what we want. AI can save time, but it cannot fully replace our own judgement.
I also think this is important in multimedia and interactive media, because code is not just technical support. It changes how the audience experiences the work. In an interactive installation, small changes in code can affect timing, movement, and response. That means the code is part of the creative result, not just something hidden in the background.
Dylan Beattie’s *The Art of Code* shows that code can also be creative and expressive, not only functional (Beattie, 2020). I think this idea is useful for interactive media, because programming is not only about making something work. It is also about making something feel right. In my project, the Arduino code directly affected how the installation responded, so I had to understand it in order to control the final result.

Don Ihde also says that technology shapes how people experience the world, not just what they see (Ihde, 1990). This is true for interactive work as well. The audience does not just look at the installation; they interact with it through the system. So the code becomes part of the experience. AI can help make the code, but I still need to know enough to decide if the result is good or not.
So I do not think programming is less important just because AI can write code. I think the role of programming is changing. We may not need to write everything from zero, but we still need to understand the logic, read the code, and fix it when AI makes mistakes. For me, that is the real reason to keep learning programming.
In the end, I think we are not learning programming only to type code. We are learning it so that we can control the tools we use and make better creative decisions. In my own Arduino project, this was very clear. AI helped me, but my own understanding helped me finish the project properly.
